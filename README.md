# Prueba de modificación del archivo README.md

En estas prácticas se detallaran los ejercicios de comandería de Git.

Para mantener un standar y saber quien modificó los archivos, proponemos el siguiente formato:

Integrante: Juan José Pérez, sus comentarios a subir en Git será por ejemplo:

JJP - 05/07/2026 - Modifiqué esta sección del archivo index.html

Integrante: Alan Brandon Cañenguez, sus comentarios a subir a Git será por ejemplo:

ABC - 04/05/2026 - Subí el archivo de imagen llamada "diagrama_v1-png" en la carpeta /backend/img/ .

Y así sucesivamente.
